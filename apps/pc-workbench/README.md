# PC 工作台

> 知行智学的PC端学习工作台 - 独立学习任务入口与过程证据采集前端

## 一、用户视角:这是什么

**PC工作台是学生的学习任务控制面板**

当学生需要在PC上完成学习任务时(阅读理解、资料检索、作文审题、错题复盘、项目学习),通过PC工作台:
1. 明确开始一个学习任务(显式授权)
2. 系统在后台记录学习过程的关键事实(前台窗口、进程信息)
3. 任务结束后查看时间线和证据卡,了解自己的学习过程

**隐私保护承诺**
- ✅ 只采集: 窗口标题、进程路径、窗口类名
- ❌ 不采集: 屏幕截图、键盘输入、剪贴板、浏览历史
- ✅ 数据存在本机,使用`local://`URI
- ✅ 学生可随时停止任务

**适用场景**
- 个人独立学习任务(PC独立路径,无需手机)
- 查看学习过程时间线和证据卡
- (待实现)接收从兴趣流桥接而来的微学习任务

## 三、技术视角:如何实现

### 技术栈(2026-09最新)

- **React**: 19.2.7 (最新稳定版)
- **Vite**: 8.2.0 (Rolldown统一打包器架构)
- **TypeScript**: 5.9.2
- **ESLint**: 10.10.0
- **Vitest**: 3.2.4 + Testing Library
- **包管理器**: pnpm 11.25+

### 架构设计

**前后端分离架构**
```
React前端 (localhost:5173)
    ↓ HTTP API
本地中枢 (127.0.0.1:8777)
    ↓ 直接调用
采集模块 (Python)
```

**API端点**
- `GET /api/dashboard` - 获取实时仪表盘数据
- `POST /api/tasks` - 创建PC学习任务
- `POST /api/phases` - 切换学习阶段
- `POST /api/tasks/stop` - 结束任务

**前端组件结构**
```
App.tsx (主应用)
  ├─ 任务控制面板
  ├─ 实时仪表盘
  ├─ 学习时间线
  └─ (待实现) 证据卡列表
```

**状态管理**
- 使用React Hooks管理本地状态
- 通过fetch API与后端通信
- 实时轮询更新仪表盘(开发中可调整间隔)

**样式设计**
- 玻璃态(Glassmorphism)设计
- 响应式布局
- 深色模式优先

### 数据流

```
1. 用户点击"开始任务"
   ↓
2. POST /api/tasks → 后端创建会话
   ↓
3. 后端启动采样循环(1秒间隔)
   ↓
4. 前端轮询 GET /api/dashboard
   ↓
5. 显示实时窗口变化
   ↓
6. 用户点击"结束任务"
   ↓
7. POST /api/tasks/stop → 停止采样
   ↓
8. 返回证据卡和时间线
```

## 二、功能视角:能做什么

### ✅ 已实现的功能

**1. PC独立学习任务管理**
- 创建PC学习任务(无需手机前置)
- 选择学习阶段: 观看/阅读/检索/写作/练习/项目
- 切换阶段(系统自动记录切换时间)
- 结束任务

**2. 实时仪表盘**
显示:
- 当前任务状态和目标
- 采集状态(运行/停止)
- 质量标记(如`process_path_unavailable`)
- 已关联的手机候选证据(仅CANDIDATE_ONLY状态,不强制升级为学习结论)

**3. 学习时间线可视化**
- 前台窗口变化时间线
- 学习阶段时间段
- 可回放的过程证据

**4. 本地优先存储**
- 所有证据使用`local://pc/`URI
- 本机证据账本,不上传云端
- 用户可随时撤回

### 🚧 部分实现

**5. 证据卡查看**
- 基础证据卡结构已实现
- 待完善: AI解释集成、复盘报告模板

### ⏳ 待实现

**6. 兴趣任务接收界面(高优先级)**
- 接收从兴趣流桥接而来的微学习任务
- 可接受/可延后/可关闭/可反馈

**7. 学习机会窗提示(高优先级)**
- 在卡顿/策略切换窗口显示实时提示
- 基于WindowScore评分(算法待实现)

**8. 完整复盘报告(中优先级)**
- 学习过程完整回放
- 证据卡列表
- AI生成的改进建议

**9. 教师复核界面(低优先级)**
- 证据卡批注
- review_status修改
- 教师评语

## API代理配置

开发环境下,Vite会将 `/api` 请求代理到本地中枢:
```
/api → http://127.0.0.1:8777
```

配置位于 `vite.config.ts`。

## 启动本机中枢

在另一个终端中启动本地中枢后端:

```powershell
cd ..\..\services\local-hub
uv run python -m zhixingzhixue_hub.pc.workbench_server
```

## 架构说明

前端使用React构建单页应用,通过fetch API与本地中枢HTTP服务通信:
- `GET /api/dashboard` - 获取仪表盘数据
- `POST /api/tasks` - 创建PC学习任务
- `POST /api/phases` - 切换学习阶段
- `POST /api/tasks/stop` - 结束任务

手机候选证据只能由学生明确关联到一个PC会话后显示,不会自动升级为学习结论或L1-L4阶段。
