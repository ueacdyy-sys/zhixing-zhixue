# 知行智学手机端视觉哲学：静默的学习脉冲

界面不把学习包装成游戏，也不把算法包装成权威。它以深墨、雾白与低饱和青绿建立安静的阅读场，留白优先于装饰；每一次从碎片内容到知识行动的转换都应像一束被点亮的细线，而不是一次强迫性的打断。

信息层级必须由证据关系决定：媒体事实是底层微弱纹理，候选概念是可见锚点，学生主动选择的学习路径才允许获得主视觉权重。卡片、时间和来源保持克制，避免用颜色、星级或分数伪造掌握程度。

交互遵循单向、渐进的阅读节奏。L1 是一屏可完成的短小解释；L2 把背景、实例、图谱与材料放进可展开的探索页；L3/L4 则将练习从“被推送的任务”还原为学生主动拿起的纸笔。每一个页面都保留返回、稍后与关闭，不让系统替学生作决定。

视觉元素采用精密的 8pt 间距系统、可读的中文无衬线字体、细描边和极浅的半透明材质，而非大面积渐变、厚重阴影或泛化的 AI 紫色。图谱以可追溯关系与来源标签组织，节点用形状与文字共同编码，不依赖颜色猜测。

整套界面应呈现为被反复推敲的学习器物：首页先回答“现在有什么值得你看”，内容页先回答“它来自哪里”，练习页先回答“你将做什么”。所有屏幕以一致的导航、字号、手势和空状态实现高级且可用的完整体验。
