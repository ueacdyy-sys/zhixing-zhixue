# 审查入口

建议审查顺序：

1. `specs/004-realtime-learning-core/spec.md`：核对实时连续证据、L0–L4 边界与多设备主链。
2. `specs/004-realtime-learning-core/source-traceability.md`：核对项目原始意图的可追溯来源。
3. `specs/004-realtime-learning-core/migration.md`：核对旧 candidate/visit 链仅作为只读迁移适配器。
4. `specs/004-realtime-learning-core/` 中的数据模型、契约、计划和任务：核对可追溯性、删除、L1 承接与验收约束。

本轮重点审查问题：实时连续媒体是否从入站到语义水位持续推进；手机、眼镜与 PC 是否都是独立业务主链；L1 是否只在稳定语义窗口和真实兴趣证据同时成立后承接；状态设备是否被越界写成诊断设备。
