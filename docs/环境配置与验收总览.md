目录：`services/local-hub/`

- Python 版本：3.12 (已更新)
- 隔离环境：`.venv`
- 依赖：pytest 9.1+、pytest-cov、ruff 0.9+
- 测试覆盖：70项集成和单元测试
- 运行入口：`python -m zhixingzhixue_hub.pc.workbench_server`
- Windows 中文路径兼容策略：通过 `PYTHONPATH` 和 `src` 目录结构确保模块导入。

- PC任务工作台 (`pc/task_workbench.py`, `pc/workbench_runtime.py`, `pc/workbench_server.py`)


- 前端框架：React 19.2.7 (最新稳定版)
- 构建工具：Vite 8.2.0 (Rolldown架构)
- 语言：TypeScript 5.9.2
- 测试：Vitest 3.2.4 + Testing Library
- Lint：ESLint 10.10.0
- pnpm workspace 已建立

功能实现：
- PC 独立学习任务入口：用户可直接在PC创建学习任务,无需手机前置
- 实时仪表盘：显示当前任务状态、采集状态、质量标记

- 隐私保护：仅采集窗口标题和进程元数据,不截图、不记录键盘/剪贴板/浏览历史

API代理配置：开发环境代理到 `http://127.0.0.1:8777` (本地中枢)

### Android 手机端

目录：`mobile-edge/third_party/screenstream_source/`

当前实现：RTSP媒体传输内核,仅在用户主动授权MediaProjection后传输媒体。

核心约束：
- 不控制第三方App,不自动滑动或播放
- 单帧/OCR、无同源音频或时间不连续媒体只能输出 `CANDIDATE_ONLY`
- 不包含广告、Firebase、云分析或上游商店变体

JDK、Gradle、Android SDK 命令行工具均已可用。已写入用户级 `ANDROID_SDK_ROOT`、`ANDROID_HOME`、`JAVA_HOME` 和 PATH。

Windows构建特殊要求：
- 必须从ASCII路径构建,避免Gradle/Kotlin Worker中文路径解码错误
- 建议使用Junction: `C:\ZhixingZhixue` → 实际项目路径
- `local.properties` 配置SDK路径,该文件不纳入版本控制

验证命令：

```powershell

# 从Junction路径构建
```
