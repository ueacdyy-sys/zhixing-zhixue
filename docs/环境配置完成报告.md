## 依赖版本更新 (2026-09-09)

### 前端工具链升级
基于2026年9月最新稳定版本,已完成以下升级:

- **pnpm**: 11.4.0 → 11.25.0 (新增任务调度器和可恢复构建)
- **React & React DOM**: 19.1.1 → 19.2.7 (最新patch版本,包含重要bug修复)
- **Vite**: 7.1.2 → 8.2.0 (重大架构升级,采用Rolldown统一打包器,性能提升10-30倍)
- **ESLint**: 9.31.0 → 10.10.0 (最新版本,改进规则检测)
- **TypeScript**: 保持 5.9.2 (稳定版本,暂不升级到7.0 Go重写版本以避免兼容性风险)

### Python环境升级
- **Python**: 3.11 → 3.12 (3.11已进入安全修复模式,3.12为当前推荐版本)
- **pytest**: 8.3 → 9.1 (最新稳定版本)

### 升级策略
采用保守渐进策略,避免大版本跨越:
- Vite 8.x: 虽为大版本升级,但Rolldown保持插件兼容性
- TypeScript: 保持5.9.2,观望7.0 Go重写版本的生态成熟度
- 所有依赖均为2026年9月验证的最新稳定版本

## 已知限制

### Android构建
- 需要Android SDK（配置在 `mobile-edge/tools/android-sdk/`）
- Windows下需要从 `C:\ZhixingZhixue` Junction访问（避免中文路径问题）
- CI中使用 `android-actions/setup-android@v3`

### Mobile-edge测试
- 部分测试需要额外依赖（httpx, fastapi, cryptography等）
- 这些依赖只在 `mobile-edge` 上下文中需要
- `services/local-hub` 已独立且完整
