# 架构基线：多入口学习过程证据平台

本文件是根目录《软件端架构方案.md》的 Spec Kit 审查副本。

```text
手机兴趣会话 ──┐                         ┌─ 手机 L0-L4 / 学习回执
PC 学习会话 ───┼→ 会话、授权、同步、证据库 ┼→ 证据卡 / PC学习工作台 / 教师复核
纸笔与第一视角 ─┘       ↓                 └─ 个性化档案
                  快路径候选分段 → 慢路径完整片段理解
                         ↓
                 知识桥接、窗口识别、质量门控、降级
```

参赛 MVP 的主入口是手机日常碎片化内容场景；PC 从第一阶段即作为本地分析中控台、证据工作台和结果呈现端。PC 也是独立学习入口和完整学习场景，但不抢占手机 MVP 的主闭环。手机、PC、纸笔/教材可独立触发会话；系统仅依据真实的任务、时间、知识与证据建立关联。

详细职责、字段、接口和测试映射见同目录 `spec.md`、`data-model.md`、`contracts/`、`plan.md` 与 `tasks.md`。
