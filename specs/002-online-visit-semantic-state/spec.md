# 在线 visit 语义状态与手机候选闭环

## 目标

把已经验收的连续媒体三模态融合，变成可持续更新、可追溯、可在手机端呈现的当前内容理解状态；不把任一单模态输出、停留时长或推送次数升级为兴趣、学习、能力或专注结论。

## 范围

- 同一 `view_visit` 内，每一条已融合窗口以不可变证据事实追加到在线语义状态。
- 语义状态按 visit 隔离；滑动、相关推荐、返回、刷新、跳出关闭 visit；Seek、回看、倍速、重播只切分 episode；后台不删除或取消已封存证据。
- 只有 `TRIMODAL`、同一 PTS 范围、同一源哈希且质量合格的窗口，才可进入当前可呈现候选集。
- `VISUAL_TEXT_NO_AUDIO`、`EVIDENCE_INCOMPLETE`、单帧、OCR 或 VLM 单独结果只可保留为证据/候选输入，不能触发 L1。
- Android 端接收的是版本化的候选卡，不是“已判定兴趣”或“学习诊断”；L1–L4 均由学生主动操作进入。

## 非目标

- 不以本阶段替代后续的状态机适配器、知识图谱、PC 学习采集、眼镜/EEG/手表接入或教师端 UI。
- 不引入 ADB 替代传输方案；该问题单列后续安全与互联任务。

## 验收场景

1. 持续播放时，已融合窗口按 PTS 追加到当前 visit 状态，先前窗口绝不被覆盖或删除。
2. 窗口乱序完成时，状态按媒体 PTS 排序；不因模型完成顺序改变媒体事实顺序。
3. 新 visit 不继承旧 visit 的在线语义；旧 visit 仍保留可复盘快照。
4. 不完整、无同源音频或单模态窗口不能取得 L1 提示资格。
5. visit 关闭后，既有候选仍可导出和复盘，但不再作为当前播放内容的顶部提醒。
