# 实施计划：PC 独立学习采集与本地工作台

## 架构

`React PC 工作台 -> 本机 HTTP 控制面 -> PC 学习运行时 -> Windows 前台窗口适配器 / SQLite+JSON 本地证据账本 -> 既有任务领域模型与时间轴`。

依赖方向保持向内：Windows API 和 HTTP 只在适配器层；运行时负责用例编排；任务、阶段、事件和时间轴继续是纯领域规则。手机候选卡采用版本化、用户明确关联会话的导入读取模型，不反向依赖 Android 或 ADB。

## TDD 切片

1. 先为前台窗口变化、会话隔离、重复采样去重和显式停止写失败测试。
2. 实现可注入的 Windows 前台窗口探针和 SQLite+JSON 本地证据账本。
3. 实现运行时编排、后台采样线程和受控 HTTP 接口。
4. 工作台接入真实 API，展示任务、采集状态、阶段/事件时间线和同会话手机候选。
5. 运行 Python 单元测试、Ruff、前端测试/Lint/Build，并以一次真实 Windows 前台切换完成正向验收。

## 非目标

不实现屏幕录制、键盘记录、浏览器私有协议、自动控制第三方应用、教师 UI、跨网传输、学习诊断或把手机候选自动转成 L1-L4。
