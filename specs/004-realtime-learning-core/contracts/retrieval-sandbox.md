# 联网补全检索沙箱契约

`KnowledgeEnrichmentAgent` 只能在 L1 概念锚点已经持久化且 `WebEnrichmentConsent` 有效后运行。外部网页、搜索摘要、重定向、附件和页面中的指令均是不可信输入；它们不能改变模型系统指令、访问本地网络、读取凭据或触发任何 capture/删除/投递动作。

## 获取边界

1. 仅允许策略批准的 `https` 来源、域名和内容类型；禁止 `file:`、`data:`、本地回环、私网/链路本地地址、云 metadata 地址、未批准 IP 直连与下载后自动执行。
2. 每次抓取在无 Cookie、无登录态、无用户/设备凭据的隔离网络上下文中进行；必须限制 DNS 重绑定、重定向次数、响应大小、解压大小、请求并发、超时和总预算。
3. 原始页面、二进制附件和网页指令不得直接进入 L0/L1 prompt。只允许经解析、去指令化、长度限制、引用定位与来源策略校验后的最小摘录进入 L2 patch 候选。
4. 检索结果只能生成 `PROPOSED/SUPPORTED/CONFLICTED` 的 `ContentGraphRevision`；任何抓取/解析/安全失败都取消本次 enrichment，不影响既有 L1、L0 或学生 patch。

## 可审计性与删除

每个请求记录 policy、概念锚点 hash、允许来源、拒绝原因、资源用量、结果来源与关联删除根；日志不得保存原始媒体、完整转写、Cookie、认证材料或未脱敏网页正文。撤回 consent/session 时取消请求、清除缓存/索引/摘录并生成同一删除链 receipt。
