# 竞赛验证画像、指标与声明等级

本文件把《需求.docx》表 4、表 9 的指标转为**实验/验收门**，不是产品内对学生的分数、能力、兴趣或专注阈值。数值只有在对应数据集、标注协议、设备配置与版本化报告齐备时才可报告。

## 1. `CompetitionValidationProfile.v1`

| 类别 | 指标 | 首期目标 | 可接受失败处理 |
|---|---|---:|---|
| 时间轴 | 同步标记附近误差 | ≤1 秒 | 超限流不参与跨模态融合 |
| 时间轴 | 普通事件误差 | ≤2 秒 | 标为并列证据或人工校准 |
| 行为事件 | 关键事件抽取 F1 | ≥0.70 | 低置信仅记录/复核，不自动建议 |
| 行为事件 | 起止时间平均误差 | ≤5 秒 | 降级为较粗窗口并标注不确定度 |

| 音频支持声明 | 已声明支持组合的真机同源采集/同步样本覆盖率 | 100% | 移除支持声明并标记受限/未知 |
| 学生可控性 | 证据解释、个人索引撤销和未来打扰撤销路径成功率 | 100% | 阻断画像/打扰策略发布 |
| 适用处理资格 | 需要独立资格的敏感/未成年人/云/导出路径拒绝无效 grant 的比例 | 100% | 对应 capability 保持 `UNAVAILABLE` |
| 切换安全 | shadow 无通知/画像/重复采集副作用且回退不复活旧通知 | 100% | 阻断 v2 发布或停用 v2 投递 |

| 正式作答零介入 | 异常退出不解除 fence；仅 closure receipt 后进入复盘 | 100% | 阻断正式学习发布 |
| 无障碍 | 关键路径通过语义/动态字体/触控/焦点/非颜色状态验收 | 100% | 阻断该页面发布 |
| 通知可恢复性 | 可修复通知阻断可定位系统设置并返回刷新；不可修复不绕过 | 100% | 不声明 heads-up 可用，保留 Discover |
| 推理可复现性 | 可用于正式结论/声明的产物具有完整 `InferenceProvenance` | 100% | 拒绝产物进入 L1/L3/L4/导出/竞赛声明 |
| 媒体模型隔离 | 不可信媒体/网页/模型输出无法越权网络、凭据、设备、导出或通知 | 100% | 停止该 worker/agent 配置发布 |
| 助手操作边界 | 未确认或越权 proposal 的第三方/系统操作拒绝率 | 100% | 禁用动作能力，只保留建议 |
| 评测治理 | 冻结测试集、许可证和 split 泄漏检查完整率 | 100% | 不得训练/调参/声明性能 |

指标的统计口径、样本量、置信区间、设备/模型/策略版本、剔除规则、失败样例与人工标注记录必须随报告归档。没有基线、对照、原始日志和错误案例时不得以单一正例宣布通过。

## 2. 单模态→组合验证与消融

每个增强模态按以下顺序验证：

1. 单设备采集是否连续、可回放、可授权、时间可标定；
2. 加入统一时间轴后是否改善指定指标；
3. 与手机/PC 基础链对照，说明增益、无增益或负增益；
4. 模态质量不合格时退出融合，基础链仍可生成符合边界的记录/证据卡。

EEG、手表、眼镜、检索、云和新模型都必须报告同批样本的对照与错误案例；没有实测增益时只能作为可选证据，不能列为 L1、掌握趋势或竞赛主张的前提。云、检索和媒体安全还必须补充攻击/撤回/跨 scope 负例，不能只展示正向样本。

## 3. 能力声明等级

| 等级 | 可使用的措辞 | 必需证据 |
|---|---|---|
| `IMPLEMENTED_VERIFIED` | 已实测/已验收 | 同配置代码、测试、真实会话、日志和验收包 |
| `IMPLEMENTED_UNVERIFIED` | 已实现，待真机/样本验证 | 代码、失败状态、尚缺的外部证据 |
| `DESIGNED_NOT_IMPLEMENTED` | 已设计，未实现 | 冻结契约、任务和测试 Oracle |
| `UNAVAILABLE` | 未接入/不可用 | UI/transport 的明确拒绝与原因 |
| `PROHIBITED` | 不允许声称/不允许采集 | 规格禁止项与负向测试 |

所有竞赛材料、演示页面、验收报告和导出摘要必须逐能力标记等级。构建、Lint、单元测试、截图、mock、离线回放、单一片段或供应商宣传均不能单独升级为 `IMPLEMENTED_VERIFIED`。

能力等级还必须同时标注 `CapabilityProfile`。例如，`LOCAL_PC_L1 / IMPLEMENTED_VERIFIED` 不意味着云、眼镜、L3/L4 或竞赛全链已完成；未接入档位必须独立标为 `UNAVAILABLE` 或 `DESIGNED_NOT_IMPLEMENTED`。
